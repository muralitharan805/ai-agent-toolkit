# Technical Stack Specialization & Career-Switch Framing

## 1. Core Stack Grounding: 5+ Years Full Stack Calibration

### Frontend: Modern Angular
- **Key Senior Signals**: Standalone Components, Signal-based state (`signal`, `computed`, `resource`), Zoneless Change Detection, Typed Forms, Functional Guards, Route Resolvers, Web Vitals (LCP, INP, CLS), Micro-frontends or Modular architecture.
- **Context to investigate**: Angular NgModules and decorator inputs remain valid in many codebases; assess modernization claims against actual Angular versions, constraints and migration scope rather than penalizing older APIs categorically.

### Backend: Node.js & NestJS
- **Key Senior Signals**: Modular architecture, Dependency Injection, Middleware pipelines, Exception Filters, Zod / class-validator DTOs, TypeORM / Prisma / raw Knex integration, JWT & RBAC functional guards, correlation ID logging.
- **Red Flags**: Unstructured Express spaghetti code masquerading as enterprise architecture, missing error boundaries, lack of input sanitization.

### Database: MySQL & SQL
- **Key Senior Signals**: Index selection (B-Tree, composite keys), query profiling (`EXPLAIN ANALYZE`), transaction locking semantics (`SELECT ... FOR UPDATE`), ACID compliance, schema migration pipelines, connection pool tuning (`max_connections`, `pool_size`).
- **Red Flags**: Trivial SELECT queries described as complex database engineering, zero awareness of N+1 query problems.

### AI & Search: Semantic Search & Vector Embeddings
- **Key Senior Signals**: Vector embedding pipelines (e.g. sentence-transformers, OpenAI embeddings), similarity metric understanding (Cosine distance, Dot product, Euclidean), chunking strategies, hybrid search (keyword full-text + vector similarity), vector storage (e.g. Pinecone, Qdrant or pgvector, subject to verified implementation).
- **Red Flags**: Vague buzzword claims like "Implemented GenAI and deep learning" without mentioning models, dimensions, retrieval latency, or embeddings generation approach.

## 2. Career-Switch Framing Playbook (Email Marketing ➔ Software Development)

### The Strategic Narrative
- **Chronology**:
  - *June 2016 – February 2021*: Email Marketing / Campaign Operations
  - *March 2021 – Present*: Full Stack Software Development (5+ years dedicated engineering experience)
- **Framing Invariants**:
  1. **Do not blend tenures**: Calculate engineering and non-engineering employment separately from verified dates. For this example, software engineering began in March 2021; do not count earlier email marketing as engineering.
  2. **Do not create an employment gap**: The transition is a deliberate, proactive career evolution, not a gap.
  3. **Visual Real Estate Allocation**:
     - Software Development (Experience + Projects + Stack): **90–95%** of visual page space.
     - Prior Marketing Background: **5–10%** of page space (a concise 1–2 line mention under earlier experience demonstrating business acumen, communication skills, and campaign analytics).
  4. **The Advantage Narrative**: Earlier marketing operations experience gives the candidate unique empathy for user acquisition, conversion funnels, data analytics, and business KPIs compared to purely academic engineers.

## 3. Indian & Global Tech Market Calibration
- **Indian Product & Service Companies**: Confirm requirements from the actual job posting; emphasize evidenced stack alignment, relevant delivery impact, and notice-period clarity where requested.
- **Remote / Global Roles**: Prioritize asynchronous communication clarity, architectural ownership, end-to-end testing, and self-directed problem-solving.
