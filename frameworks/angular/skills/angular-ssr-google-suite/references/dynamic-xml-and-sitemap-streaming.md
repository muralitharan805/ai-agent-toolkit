# Dynamic XML Response Streaming & Cloudflare Edge Routing

This reference details the mechanics of high-performance XML sitemap streaming and Cloudflare Pages edge routing optimization for Angular Server-Side Rendered applications.

---

## 1. Dynamic Sitemap Streaming inside `src/server.ts`

In modern Angular SSR (`@angular/ssr`), the edge entrypoint (`src/server.ts`) intercepts incoming HTTP requests before delegating to `AngularAppEngine`.

### Fast-Path Edge Interception
Rather than compiling Angular component templates to serve an XML file, intercept `/sitemap.xml` directly in the native Web `fetch` handler:

```typescript
export const reqHandler = createRequestHandler(async (req: Request): Promise<Response> => {
  const url = new URL(req.url);
  const pathname = url.pathname.toLowerCase().replace(/\/$/, '');

  if (pathname === '/sitemap.xml') {
    return new Response(SITEMAP_XML, {
      status: 200,
      headers: {
        'Content-Type': 'application/xml; charset=UTF-8',
        'Cache-Control': 'public, max-age=86400, s-maxage=86400'
      }
    });
  }

  // Fallback to Angular SSR engine
  const response = await angularApp.handle(req);
  return response ?? new Response('Not Found', { status: 404 });
});
```

### Key Benefits
1. **Zero Cold-Start Overhead**: Crawler requests for `/sitemap.xml` bypass heavy Angular SSR dependency graph instantiation.
2. **Deterministic Content-Type**: Ensures `application/xml; charset=UTF-8`, avoiding Google Search Console parsing warnings (*"Your sitemap appears to be an HTML page"*).
3. **Edge Caching**: `s-maxage=86400` allows Cloudflare's global CDN caches to serve the sitemap directly from edge POPs for 24 hours.

## 2. Edge Route Bypass Optimization (`public/_routes.json`)

Cloudflare Pages Functions bill invocations based on worker execution count. By default, every request triggers the server function unless explicitly excluded.

### The Manifest (`public/_routes.json`)
```json
{
  "version": 1,
  "include": ["/*"],
  "exclude": [
    "/sitemap.xml",
    "/robots.txt",
    "/ads.txt",
    "/favicon.ico",
    "/assets/*"
  ]
}
```

### How Cloudflare Evaluates `_routes.json`
- Rules under `exclude` take strict precedence over `include`.
- Static files matching `exclude` are streamed directly from Cloudflare's static CDN storage without waking the V8 isolate worker, cutting compute costs to zero for static assets and robots protocol.

---

## 3. Robots.txt Synchronization

Deploy `public/robots.txt` at the root domain:
```text
User-agent: *
Allow: /

Sitemap: https://yourdomain.com/sitemap.xml
```

## 4. Keyword-Rich Pre-Rendered Route Titles

Search engine bots index the raw HTML generated by Angular SSR during server execution. Bare route titles (e.g. `'Home'`, `'Login'`) lead to immediate ranking deprioritization.

Always define descriptive titles in `app.routes.ts`:
```typescript
export const routes: Routes = [
  {
    path: '',
    title: 'Personal Finance, Net Worth & Asset Allocation Tracker',
    loadComponent: () => import('./features/home/home.component').then(m => m.HomeComponent)
  },
  {
    path: 'privacy',
    title: 'Privacy Policy & Cookie Disclosures',
    loadComponent: () => import('./features/legal/privacy-policy.component').then(m => m.PrivacyPolicyComponent)
  },
  {
    path: 'terms',
    title: 'Terms of Service & User Agreement',
    loadComponent: () => import('./features/legal/terms-of-service.component').then(m => m.TermsOfServiceComponent)
  }
];
```
